# Эмулятор оболочки ОС — вариант 19

Проект реализует этапы 1–3 практической работы по дисциплине
«Конфигурационное управление».

## Возможности

- Консольный интерфейс с приглашением, содержащим имя VFS.
- Раскрытие переменных окружения (`$HOME`, `${HOME}`) и разбор аргументов.
- Команды-заглушки `ls` и `cd`, команда `exit`.
- Параметры `--vfs` и `--script`.
- Вывод параметров запуска.
- Выполнение стартового скрипта с отображением команд, пропуском ошибочных
  строк и сообщением о номере строки с ошибкой.
- Загрузка и проверка JSON-файла VFS в память.
- Примеры VFS с минимальной структурой, несколькими файлами и глубокой
  вложенностью.

На этапе 3 `ls` и `cd` пока остаются заглушками: полноценная работа этих
команд и команды `rev`, `pwd`, `find` относятся к этапу 4 варианта 19.

## Структура проекта

- `src/main.py` — исходный код.
- `tests/` — автоматические тесты.
- `vfs/` — примеры JSON-файлов виртуальной файловой системы.
- `scripts/` — стартовые и оболочечные тестовые скрипты.
- `run.sh` — скрипт запуска.
- `.gitignore` — исключения для Git.

## Запуск

Из корневой папки проекта:

```sh
./run.sh
```

Указать файл VFS:

```sh
./run.sh --vfs vfs/multiple_files.json
```

Запустить стартовый скрипт:

```sh
./run.sh --vfs vfs/minimal.json --script scripts/stage2_demo.txt
```

Примеры запуска из оболочки ОС:

```sh
sh scripts/run_minimal.sh
sh scripts/run_multiple.sh
sh scripts/run_deep.sh
```

## Формат JSON VFS

```json
{
  "name": "MyVFS",
  "root": {
    "type": "directory",
    "children": {
      "hello.txt": {
        "type": "file",
        "encoding": "utf-8",
        "content": "Hello"
      },
      "docs": {
        "type": "directory",
        "children": {}
      }
    }
  }
}
```

Каталоги имеют тип `directory` и объект `children`. Файлы имеют тип `file`,
кодировку и содержимое. Для двоичных данных можно указать `encoding: base64`
и сохранить содержимое в Base64. Файловая структура загружается из JSON в
память; программа не распаковывает архивы и не записывает изменения в
исходный JSON-файл.

## Тестирование

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют раскрытие переменных окружения, загрузку корректной VFS,
обработку отсутствующего файла и неправильного JSON, а также пропуск
ошибочной команды в стартовом скрипте.

## Примеры ошибок

- Неизвестная команда: `unknown_command`.
- Несуществующий файл VFS: `--vfs vfs/missing.json`.
- Некорректный JSON: сообщение об ошибке загрузки VFS.
- Ошибка команды в стартовом скрипте: выполнение продолжается, выводится
  номер строки с ошибкой.
